## Stage (a) Scout — DONE

Two parallel scout agents (app-review/forum vein + Reddit-pivot vein). Candidates surfaced:

1. **Vinted size-bucket confusion** — 8 independent Mumsnet threads, 2025–2026, unresolved.
   Vinted collapsed numeric sizes into letter buckets (e.g. UK 10 → "S/Medium"); buyers tick one
   size and get UK 8–22 results; sellers list bucket-only with no numeric size. Existing tool
   (VintHelper size converter) covers country conversion, NOT the bucket problem. Thread URLs in
   backlog/rejected updates and in the app manifest evidence when built.
2. **Petite-friendly brand directory** — 6 Mumsnet threads across years, same list rebuilt from
   scratch each time, no canonical resource. → backlog.
3. **Wardrobe cost-per-wear / wear analytics without paywall** — recurring complaints: Indyx paywalls
   analytics (~$20 AUD/mo), Acloset caps items + heavy ads + locked users out of own data (€30/mo).
   YouLookFab threads show people still hand-rolling spreadsheets. → backlog (differentiation: local-only,
   no cap, no account).
4. **EU↔US suit/jacket size conversion** — 4-5 Styleforum threads re-deriving the math manually. → folded
   into consideration; general conversion charts exist widely, weaker gap than Vinted bucket problem.
5. **Outfit-suggestion quality complaints** (Whering/Cladwell "AI" suggestions nonsensical/repetitive,
   no weather awareness) — moderate; saturated market. → backlog note.
6. **Luxury authentication trust gap** — strong pain (PurseForum, years), but genuinely reliable
   authentication cannot be done as a zero-cost client-side app; shipping an unreliable one is exactly
   what users complain about. → REJECTED.
